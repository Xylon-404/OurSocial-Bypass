# ⚙️ How It Works

📌 Script run করার পর প্রথমে আপনার refer link দিন।

📌 তারপর কত account create করবেন সেটা দিন।

📌 এরপর `(y/n)` এ `y` দিয়ে enter করুন।

---

## 🤖 What The Script Does

🔹 আপনার refer link ব্যবহার করে new account create করে  
🔹 তারপর auto login করে  
🔹 এরপর ১৮+ image upload করে  
🔹 New account create হওয়ার সাথে সাথে refer point ও increase হয় 😎🔥
